AQUANEX – Waterlogging Prediction System
About the Project
AQUANEX is a waterlogging prediction project designed to help identify and predict potential waterlogging conditions.

Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Java and Spring Boot
Database: MySQL
Project Features
Waterlogging prediction
User registration and management
Frontend and backend integration
How to Run
Configure the MySQL database.
Update the database connection settings.
Start the backend application.
Open the frontend in a web browser.
